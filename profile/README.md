## Winplot Highlights

- **Function Graph:** Winplot function graph plots an explicit curve, y as a function of x, for the algebra and precalculus problems that start a homework set.
- **Implicit Plot:** Winplot implicit plot draws a relation that is not solved for y, such as a circle or another level curve the textbook left in two variables.
- **3D Surface:** Winplot 3d surface shows z as a function of x and y so a multivariable sketch can be turned and inspected.
- **Parametric Plot:** Winplot parametric plot follows x and y as functions of a third variable, which is the natural view for many motion and path problems.
- **Equation Animate:** Winplot equation animate moves a coefficient or a parameter so a family of curves changes slowly enough to describe in class or at home.

## What Is Winplot

Winplot is a graphing helper for school mathematics, from explicit curves through surfaces and moving parameters. Winplot function graph covers the ordinary worksheet: one equation, one window, one shape to compare with your algebra. Winplot implicit plot is the companion for relations you cannot neatly solve for y. Both belong on a home desk or in a classroom where the goal is to see the figure the problem describes.

When the course leaves the plane, Winplot 3d surface gives a surface you can rotate instead of imagining from a static textbook picture. Winplot parametric plot covers paths, including curves that double back. Winplot equation animate is the piece many classes remember: a slider or a frame-by-frame change in a constant, so a family is not ten separate sketches. None of this requires a large lab. A laptop and the problem sheet are enough.

Use one mode at a time. Finish Winplot function graph before you open Winplot implicit plot, and do not jump to Winplot 3d surface until the 2D window makes sense. Build Winplot parametric plot from the pair of formulas in the book. Turn on Winplot equation animate only after the still picture is correct, then watch one parameter move. That order keeps a study hour calm and makes the saved picture match a single question.

## Starting with Winplot

Prerequisites: A compatible computer, a graphing problem from class, and permission to run Winplot.

1. **Prepare:** Decide whether the problem is explicit, implicit, parametric, or a surface.
2. **Start Explicit:** If y is given as a function of x, use Winplot function graph and set the window from the sheet.
3. **Use Implicit When Needed:** If the relation is not solved for y, switch to Winplot implicit plot.
4. **Leave The Plane Carefully:** Open Winplot 3d surface only for a z formula you have written down.
5. **Trace A Path:** Enter both component formulas in Winplot parametric plot and mark the parameter interval.
6. **Move One Constant:** After the still curve looks right, use Winplot equation animate on a single coefficient.
